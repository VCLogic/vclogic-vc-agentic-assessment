# Rehearsal classifier registry

This directory is generated by:

```bash
uv run python scripts/build_rehearsal_classifier_registry.py \
  --config configs/rehearsal-classifier-build.toml
```

The registry contains non-executable JSON linear classifiers. Each investor has a
production artifact for live pitches and, where class counts permit, a separately
fit artifact for every historical episode with that episode excluded. Runtime
loading verifies every artifact's SHA-256 digest and refuses to replace a missing
historical fold with the production model.

`build-report.json` records unavailable folds and their reasons. Generated artifact
files can be rebuilt deterministically from the canonical registry and configuration.
